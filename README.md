## 📌 Overview

**Game Project** is a C++-based game created as a practical implementation of the programming and Computer Science concepts learned throughout the course.

The project focuses on combining **programming fundamentals, logical problem-solving, control structures, functions, data handling, and interactive console input/output** into a single playable application.

Rather than implementing isolated programming exercises, this project brings multiple concepts together to create a complete game-oriented program.

## ✨ Key Features

* 🎮 Interactive console-based gameplay

## 🚀 Getting Started

### Prerequisites

Make sure you have a C++ compiler installed.

Recommended options:

* **GCC / MinGW**
* **Microsoft Visual C++**
* **Clang**
* **Visual Studio**
* **Code::Blocks**
* **VS Code with a C++ compiler**

---

### 🔧 Installation

Clone the repository:

```bash
git clone https://github.com/muffasernaeem302/Game-Project.git
```

Navigate to the project directory:

```bash
cd Game-Project
```

---

## ▶️ Running the Project

### Using g++

Compile the project:

```bash
g++ main.cpp -o game
```

Run the executable:

**Windows:**

```bash
game.exe
```

**Linux / macOS:**

```bash
./game
```

### Using an IDE

Alternatively, open the project in your preferred C++ IDE and compile/run `main.cpp`.
